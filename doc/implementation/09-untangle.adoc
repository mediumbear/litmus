== Untangle

:litmus-dir: src

Tangle takes the documents to the files. Untangle carries changes the other way: a person or an agent edits a tangled file and tests it as usual, and untangle puts the edit into the document blocks the lines came from. The prose is still the writer's. Untangle says where it is needed.

The method follows from one fact. Every excerpt is used exactly once (C2, C3), so every line of a tangled file comes from exactly one line of the document set, and the map, or rather the runs behind it, say which. The steps are:

. Tangle the documents in memory. This is the _base_ (U1).
. Compare each base file with the file on disk, line by line (U2).
. Turn each difference into an edit of a document line (U3, U4, U5).
. Apply the edits, tangle the new documents in memory, and require the result to equal the files on disk, byte for byte (U9). If it does not, write nothing.

The last step is what makes untangle exact. The earlier steps are free to be clever and to be wrong, because a wrong guess cannot get past the check. The tests lean on this: they make random documents, change their tangled files at random, and demand that untangle either reports a line it cannot place or gives documents that tangle to exactly the changed files.

The chapter has three files: `diff.zig` finds the differences, `untangle.zig` plans, applies and checks the edits, and `sync.zig` decides in which direction to go. The command that ties them to the disk is in chapter 8.

A `Hunk` says that base lines `[a, a_end)` were replaced by changed lines `[b, b_end)`. Either range may be empty, which makes the hunk a pure insertion or a pure deletion. A diff is a list of hunks in order.

Most edits are small, and a diff that cannot afford to find the best answer should still give a right one. So the search is limited: past `max_edits` edits, the whole middle of the two texts is reported as one hunk. That is coarser, and still exact. A formatter that rewrites a whole file ends up here.

`diff` first trims the lines that the two texts have in common at the start and at the end, which settles most cases at once. If one side is empty after that, it is one hunk. Otherwise it asks Myers' algorithm which lines are deleted and which are inserted, and turns the answer into hunks.

/// The hunks that turn `base` into `changed`, in order. The common start and end
/// are trimmed first, since most edits are small, and Myers' O(ND) algorithm runs
/// on what is left.
pub fn diff(arena: Allocator, base: []const []const u8, changed: []const []const u8) Allocator.Error![]const Hunk {
    var start: usize = 0;
    while (start < base.len and start < changed.len and same(base[start], changed[start])) start += 1;
    var end: usize = 0;
    while (end < base.len - start and end < changed.len - start and
        same(base[base.len - 1 - end], changed[changed.len - 1 - end])) end += 1;
    const a = base[start .. base.len - end];
    const b = changed[start .. changed.len - end];

    var hunks: std.ArrayList(Hunk) = .empty;
    if (a.len == 0 and b.len == 0) return hunks.items;
    if (a.len == 0 or b.len == 0) {
        try hunks.append(arena, .{ .a = @intCast(start), .a_end = @intCast(start + a.len), .b = @intCast(start), .b_end = @intCast(start + b.len) });
        return hunks.items;
    }

    const deleted = try arena.alloc(bool, a.len);
    const inserted = try arena.alloc(bool, b.len);
    @memset(deleted, false);
    @memset(inserted, false);
    if (!try myers(arena, a, b, deleted, inserted)) {
        @memset(deleted, true);
        @memset(inserted, true);
    }

    // Lines that were neither deleted nor inserted pair up in order. What lies between
    // two such pairs is one hunk.
    … diff, the hunks
    return hunks.items;
}

Myers' algorithm looks for the shortest list of single-line edits. It works in rounds: round `d` finds how far along each diagonal of the comparison one can get with `d` edits, and stops when one reaches the end of both texts. The state before each round is kept, so that the path can be walked back from the end. The walk marks the deleted and the inserted lines.

The cost is proportional to the size of the texts times the number of edits, which is why the number of edits is limited.

[source,zig]
----
/// Marks the lines of `a` that are deleted and the lines of `b` that are inserted.
/// Returns false if more than `max_edits` edits would be needed.
fn myers(arena: Allocator, a: []const []const u8, b: []const []const u8, deleted: []bool, inserted: []bool) Allocator.Error!bool {
    const n: i64 = @intCast(a.len);
    const m: i64 = @intCast(b.len);
    const limit: i64 = @intCast(@min(max_edits, a.len + b.len));
    const width: usize = @intCast(2 * limit + 3);
    const offset: i64 = limit + 1;
    var v = try arena.alloc(i64, width);
    @memset(v, 0);
    // The state before each round of edits, kept to walk back from the end.
    var trace: std.ArrayList([]i64) = .empty;

    var d: i64 = 0;
    const found = search: while (d <= limit) : (d += 1) {
        try trace.append(arena, try arena.dupe(i64, v));
        var k = -d;
        while (k <= d) : (k += 2) {
            const down = k == -d or (k != d and v[@intCast(offset + k - 1)] < v[@intCast(offset + k + 1)]);
            var x: i64 = if (down) v[@intCast(offset + k + 1)] else v[@intCast(offset + k - 1)] + 1;
            var y = x - k;
            while (x < n and y < m and same(a[@intCast(x)], b[@intCast(y)])) {
                x += 1;
                y += 1;
            }
            v[@intCast(offset + k)] = x;
            if (x >= n and y >= m) break :search true;
        }
    } else false;
    if (!found) return false;

    var x = n;
    var y = m;
    var round = d;
    while (round > 0) : (round -= 1) {
        const before = trace.items[@intCast(round)];
        const k = x - y;
        const down = k == -round or (k != round and before[@intCast(offset + k - 1)] < before[@intCast(offset + k + 1)]);
        const prev_k = if (down) k + 1 else k - 1;
        const prev_x = before[@intCast(offset + prev_k)];
        const prev_y = prev_x - prev_k;
        if (down) {
            inserted[@intCast(prev_y)] = true;
        } else {
            deleted[@intCast(prev_x)] = true;
        }
        x = prev_x;
        y = prev_y;
    }
    return true;
}

const t = std.testing;

fn lines(arena: Allocator, text: []const u8) ![]const []const u8 {
    return @import("scan.zig").splitLines(arena, text);
}

/// Applies the hunks to `base`: unchanged lines are copied, and each hunk's range is
/// replaced by the changed lines. The result must be `changed`.
fn expectApplies(base: []const []const u8, changed: []const []const u8, hunks: []const Hunk) !void {
    var at: u32 = 0;
    var out: std.ArrayList([]const u8) = .empty;
    defer out.deinit(t.allocator);
    for (hunks) |h| {
        try t.expect(h.a >= at);
        for (base[at..h.a]) |line| try out.append(t.allocator, line);
        for (changed[h.b..h.b_end]) |line| try out.append(t.allocator, line);
        at = h.a_end;
    }
    for (base[at..]) |line| try out.append(t.allocator, line);
    try t.expectEqual(changed.len, out.items.len);
    for (changed, out.items) |want, got| try t.expectEqualStrings(want, got);
}

fn expectHunks(base: []const u8, changed: []const u8, want: []const Hunk) !void {
    var arena_state = std.heap.ArenaAllocator.init(t.allocator);
    defer arena_state.deinit();
    const a = arena_state.allocator();
    const x = try lines(a, base);
    const y = try lines(a, changed);
    const got = try diff(a, x, y);
    try t.expectEqual(want.len, got.len);
    for (want, got) |w, g| try t.expectEqual(w, g);
    try expectApplies(x, y, got);
}

An `Edit` changes one line of one document: it replaces it, deletes it, or inserts text before it. Lines are counted as they were before any edit, which is what keeps edits independent of each other. There is no insert-after: inserting after line `n` is inserting before line `n + 1`, and a block always has a line after its last, its closing line.

pub const Plan = struct {
    arena: Allocator,
    docs: []const Document,
    edits: std.ArrayList(Edit) = .empty,
    problems: std.ArrayList(Problem) = .empty,
    placements: std.ArrayList(Placement) = .empty,
    growth: std.ArrayList(Growth) = .empty,
    growth_index: std.AutoHashMapUnmanaged(*const Block, usize) = .empty,
    changed: u32 = 0,
    removed: u32 = 0,
    added: u32 = 0,

    pub fn init(arena: Allocator, docs: []const Document) Plan {
        return .{ .arena = arena, .docs = docs };
    }

    fn docPath(self: *const Plan, doc: u32) []const u8 {
        return self.docs[doc].path;
    }

    fn problem(self: *Plan, file: []const u8, line: u32, comptime fmt: []const u8, args: anytype) !void {
        try self.problems.append(self.arena, .{ .file = file, .line = line, .message = try std.fmt.allocPrint(self.arena, fmt, args) });
    }

    fn grew(self: *Plan, block: *const Block, lines: u32) !void {
        const slot = try self.growth_index.getOrPut(self.arena, block);
        if (!slot.found_existing) {
            slot.value_ptr.* = self.growth.items.len;
            try self.growth.append(self.arena, .{ .block = block, .added = 0 });
        }
        self.growth.items[slot.value_ptr.*].added += lines;
        self.added += lines;
    }

const Origin = struct {
    run: types.Run,
    doc_line: u32,
    /// What the excerpt commands around it put in front of the line (T2).
    prefix: []const u8,

fn prefixOf(file: tangle.Tangled, run: types.Run) []const u8 {
    if (run.expansion == types.no_expansion) return "";
    return file.expansions[run.expansion].prefix;
}

fn originOf(file: tangle.Tangled, line: u32) ?Origin {
    const at = map.findRun(file.runs, line) orelse return null;
    const run = file.runs[at];
    return .{ .run = run, .doc_line = run.doc_line + (line - run.line), .prefix = prefixOf(file, run) };

Within a hunk, lines are paired by position. The first `min(k, m)` base lines were changed into the first `min(k, m)` new lines. If there are more base lines, the rest were removed. If there are more new lines, the rest were added, after the last pair. A diff cannot say better, and it does not have to: whatever is paired, the final check sees the result.

=== Changing and removing (U3)

A changed line goes back to the document line it came from, with the indent taken off. If the new text does not start with the prefix of its excerpt, the excerpt's indent was lost, and that is U5. So is a line that is only the prefix: nothing in a document gives that, since an empty line stays empty in the file (T2), and a line of spaces gets the prefix in front of it.

A removed line is removed from the document.

/// U3: a changed line is changed at the document line it came from.
fn changeLine(plan: *Plan, file: tangle.Tangled, n: u32, text: []const u8, new_n: u32) !void {
    const origin = originOf(file, n) orelse return;
    var stripped: []const u8 = "";
    if (text.len > 0) {

=== Adding lines (U4)

Added lines are placed in groups: the lines that were added at one point of the file. `startWithAll` says whether a group fits a place, and `allEmpty` whether the group has any text at all.

… startWithAll :file: untangle.zig
[source,zig]
----
/// Whether every line can be a line of a block whose excerpt puts `prefix` in front of its
/// lines: empty, or the prefix and then something. A line that is only the prefix cannot
/// come from any line of a document, since empty lines stay empty (T2).
fn startWithAll(lines: []const []const u8, prefix: []const u8) bool {
    for (lines) |line| {
        if (line.len == 0) continue;
        if (line.len <= prefix.len or !std.mem.startsWith(u8, line, prefix)) return false;
    }
    return true;
}

fn allEmpty(lines: []const []const u8) bool {
    for (lines) |line| if (line.len > 0) return false;
    return true;
}
----

Where a group goes depends on the place in the file where it was added, the gap between two lines. The cases are tried in turn.

When the gap is between two lines of one run, nothing is in between, and the lines go into that block at that place. When it is not, there are _candidates_: the excerpt commands next to the gap. A command is a candidate _after_ it if its excerpt ends at the gap, and _before_ it if its excerpt begins there. Candidates are ordered innermost first, and where two are equally deep the one before the gap comes first.

… Candidate :file: untangle.zig
[source,zig]
----
const Candidate = struct { exp: u32, after: bool };

/// Innermost first. Where two are equally deep, the one before the gap comes first.
fn innerFirst(expansions: []const types.Expansion, a: Candidate, b: Candidate) bool {
    const x = expansions[a.exp];
    const y = expansions[b.exp];
    if (x.depth != y.depth) return x.depth > y.depth;
    if (a.after != b.after) return a.after;
    return a.exp < b.exp;
}

=== Applying the edits

Edits are sorted by document and line. `shifted` tells where a line is after the edits: a line moves down for each line inserted before it, and up for each deleted above it. The report needs it, because the line numbers of the documents have changed by the time it is printed.

… sortedEdits :file: untangle.zig
[source,zig]
----
/// The edits in the order of the documents and their lines. The sort is stable, so lines
/// inserted at one place keep their order.
pub fn sortedEdits(arena: Allocator, edits: []const Edit) ![]const Edit {
    const sorted = try arena.dupe(Edit, edits);
    const Order = struct {
        fn less(_: void, a: Edit, b: Edit) bool {
            if (a.doc != b.doc) return a.doc < b.doc;
            return a.line < b.line;
        }
    };
    std.mem.sort(Edit, sorted, {}, Order.less);
    return sorted;
}

/// Where a line of a document is after the edits: lines inserted before it, or removed
/// above it, move it.
pub fn shifted(sorted: []const Edit, doc: u32, line: u32) u32 {
    var result: i64 = line;
    for (sorted) |e| {
        if (e.doc != doc or e.line > line) continue;
        switch (e.kind) {
            .insert => result += 1,
            .delete => if (e.line < line) {
                result -= 1;
            },
            .replace => {},
        }
    }
    return @intCast(result);
}
----

`applyEdits` makes new documents. It goes through each edited document's lines once. For each original line it emits what is inserted before it, and then the line itself: replaced, left out, or as it was. Documents that have no edits are not copied, and are recognised by the very same slice of lines.

… applyEdits :file: untangle.zig
[source,zig]
----
/// Applies the edits to the documents, in one pass over each document's lines: for every
/// original line, what is inserted before it, then the line itself (replaced, deleted,
/// or kept). Edits name original line numbers, so they never disturb each other.
pub fn applyEdits(arena: Allocator, docs: []const Document, edits: []const Edit) ![]const Document {
    const sorted = try sortedEdits(arena, edits);

    const result = try arena.dupe(Document, docs);
    var at: usize = 0;
    for (result, 0..) |*doc, index| {
        const first = at;
        while (at < sorted.len and sorted[at].doc == index) at += 1;
        const mine = sorted[first..at];
        if (mine.len == 0) continue;

        var lines: std.ArrayList([]const u8) = .empty;
        var next: usize = 0;
        for (doc.lines, 0..) |line, n| {
            const number: u32 = @intCast(n + 1);
            while (next < mine.len and mine[next].line == number and mine[next].kind == .insert) : (next += 1) {
                try lines.append(arena, mine[next].text);
            }
            if (next < mine.len and mine[next].line == number) {
                if (mine[next].kind == .replace) try lines.append(arena, mine[next].text);
                next += 1;
            } else {
                try lines.append(arena, line);
            }
        }
        doc.lines = lines.items;
    }
    return result;
}

/// The text of a document, as it is written to disk.
pub fn render(arena: Allocator, doc: Document) ![]const u8 {
    var out: std.ArrayList(u8) = .empty;
    for (doc.lines, 0..) |line, n| {
        try out.appendSlice(arena, line);
        if (n + 1 < doc.lines.len or doc.final_newline) try out.append(arena, '\n');
    }
    return out.items;
}

    texts: []const []const u8,

        for (self.docs, self.texts) |doc, text| if (std.mem.eql(u8, doc.path, path)) return text;

const words = [_][]const u8{ "alpha", "beta", "", "  x", "}", "{ y", "  ", "gamma delta" };
const indents = [_][]const u8{ "", " ", "  ", "\t" };

/// A random document: a file root, and excerpts that are each used once by an earlier one.
fn randomDocument(a: Allocator, random: std.Random) ![]const u8 {
    const count = random.uintLessThan(usize, 6);
    const containers = try a.alloc(std.ArrayList([]const u8), count + 1);
    for (containers) |*c| {
        c.* = .empty;
        for (0..1 + random.uintLessThan(usize, 5)) |_| try c.append(a, words[random.uintLessThan(usize, words.len)]);
    }
    // Container 0 is the root; excerpt j is container j, used once by an earlier one.
    var j = count;
    while (j >= 1) : (j -= 1) {
        const parent = random.uintLessThan(usize, j);
        const command = try std.fmt.allocPrint(a, "{s}… e{d}", .{ indents[random.uintLessThan(usize, indents.len)], j });
        const at = random.uintLessThan(usize, containers[parent].items.len + 1);
        try containers[parent].insert(a, at, command);
    }
    var out: std.ArrayList(u8) = .empty;
    for (containers, 0..) |c, n| {
        const label = if (n == 0) try a.dupe(u8, "… :file: f.txt") else try std.fmt.allocPrint(a, "… e{d} :file: f.txt", .{n});
        // Some excerpts are split in two blocks, with prose between.
        const split = if (n > 0 and c.items.len > 1 and random.boolean()) random.uintLessThan(usize, c.items.len - 1) + 1 else c.items.len;
        const parts = [_][]const []const u8{ c.items[0..split], c.items[split..] };
        for (parts, 0..) |part, p| {
            if (p == 1 and part.len == 0) break;
            try out.print(a, "{s}\n----\n", .{label});
            for (part) |line| try out.print(a, "{s}\n", .{line});
            try out.appendSlice(a, "----\n\nSome prose.\n\n");
        }
    }
    return out.items;
}

/// Random edits of a tangled file: lines changed, removed, and added, mostly with the indent of
/// the line next to them, and sometimes without it.
fn randomEdits(a: Allocator, random: std.Random, text: []const u8) ![]const u8 {
    const lines = try scan.splitLines(a, text);
    var out: std.ArrayList(u8) = .empty;
    if (random.uintLessThan(u8, 10) == 0) try out.appendSlice(a, "first\n");
    for (lines) |line| {
        var lead: usize = 0;
        while (lead < line.len and (line[lead] == ' ' or line[lead] == '\t')) lead += 1;
        const keep = if (random.uintLessThan(u8, 8) == 0 and lead > 0) lead - 1 else lead;
        const new = words[random.uintLessThan(usize, words.len)];
        switch (random.uintLessThan(u8, 10)) {
            0 => {},
            1 => try out.print(a, "{s}{s}\n", .{ line[0..keep], new }),
            2 => try out.print(a, "{s}\n{s}{s}\n", .{ line, line[0..keep], new }),
            else => try out.print(a, "{s}\n", .{line}),
        }
    }
    return out.items;
}

For one file the answer is one of five states. The file changed, the documents changed, both, neither, or, with no map entry to compare to, not known. A file that is missing counts as the documents' change, since tangle writes it again. `stateOf` takes the three hashes: the map's, the documents', and the file's.

/// What changed for one tangled file since tangle last wrote it.
pub const FileState = enum {
    /// Neither the file nor the documents' code.
    in_sync,
    /// The file on disk, and only that.
    files_changed,
    /// The documents' code, and only that. A file that is missing counts here, since
    /// tangle writes it again.
    documents_changed,
    both_changed,
    /// There is no map entry, and the file differs from its tangled text, so which side
    /// changed is not known.
    unknown,
};

/// `recorded` is the hash in the map, `tangled` is the hash of the text the documents tangle to, and
/// `on_disk` is the hash of the file, or null if it does not exist.
pub fn stateOf(recorded: ?[]const u8, tangled: []const u8, on_disk: ?[]const u8) FileState {
    const disk = on_disk orelse return .documents_changed;
    const entry = recorded orelse return if (std.mem.eql(u8, disk, tangled)) .in_sync else .unknown;
    const files = !std.mem.eql(u8, disk, entry);
    const documents = !std.mem.eql(u8, tangled, entry);
    if (files and documents) return .both_changed;
    if (files) return .files_changed;
    if (documents) return .documents_changed;
    return .in_sync;
}

pub const Direction = enum { in_sync, untangle, tangle, stop };

pub fn direction(states: []const FileState) Direction {
    var files = false;
    var documents = false;
    for (states) |state| switch (state) {
        .in_sync => {},
        .files_changed => files = true,
        .documents_changed => documents = true,
        .both_changed, .unknown => return .stop,
    };
    if (files and documents) return .stop;
    if (files) return .untangle;
    if (documents) return .tangle;
    return .in_sync;
}
